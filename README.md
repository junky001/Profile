# Jounkey Olang | Web Developer Profile

My personal profile website, built to show clients my work as a web developer, graphics designer and video editor.

**Live site:** https://junky001.github.io/Profile/

## About this project

I'm a software developer and student at Jaramogi Oginga Odinga University of Science and Technology (JOOUST). I built this site from scratch to present my services and recent projects in one place, and to make it easy for clients to contact me.

## What's on the site

- **About me:** my three roles (software developer, graphics designer, video editor), each with an image
- **Recent work:** websites and apps I've built for schools, shops and small businesses
- **Skills:** what I build with and what I'm learning
- **FAQ:** answers to common questions from clients
- **Contact form:** sends a ready-written message to my WhatsApp

## Built with

- HTML
- CSS (custom properties, grid, flexbox, responsive layout)
- JavaScript (mobile menu and the contact form)
- Hosted free on GitHub Pages

## Project structure

```
Profile/
├── index.html    # page content
├── styles.css    # all styling
├── script.js     # menu and contact form
└── images/       # photos and graphics
```

## Run it on your computer

1. Download or clone this repository.
2. Open `index.html` in your browser.

No installation is needed.
